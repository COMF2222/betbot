# Недельный отчёт и движение коэффициентов

Недельный отчёт отправляется в подключённые группы и каналы в понедельник, по умолчанию в 12:00 МСК. Он охватывает предыдущую календарную неделю: понедельник 00:00 — воскресенье 23:59. Бот ждёт результатов всех опубликованных карт. Если запуск пропущен, отчёт доставляется после восстановления работы, один раз для каждого места публикации.

Короткая подпись к картинке содержит общий результат, ожидание рынка с количеством карт, для которых были исходные парные цены, группы ☆, ★, ★★ и ★★★ и выше, самый уверенный промах, наблюдавшийся камбэк победившей команды, результат «только драфт» и накопленный счёт. Отсутствующие цены не превращаются в нулевую вероятность. Прогнозы с подтверждённым ранним временем и разборы с задержкой считаются отдельно.

Пример формата с условными числами:

```text
📈 35 из 53 за неделю, рынок ждал 34.1

👉 По звёздам: ★ 20 из 28, ★★ 8 из 16, ★★★ и выше 7 из 9 (рынок ждал 5.8)
👉 Промах недели: Команда A 65% ★★★ против Команды B, карта 2 (06.10)
👉 Камбэк недели: Команда C против Команды D, карта 1 (10.10), по ходу рынок давал им 3%
ℹ️ По одним героям 26 из 53. С запуска 72 из 108
```

## Уведомления о коэффициентах

В админке: **Публикации → Движение кэфов**. Можно включать/выключать сообщения и выбирать относительный рост: 10%, 20% или 30%.

По умолчанию уведомляем, когда цена Polymarket на фаворита исходного прогноза выросла минимум на **20%** и минимум на **0,20**. После первого сообщения следующий рост считается от цены в последнем уведомлении. Пауза между сообщениями — 10 минут, максимум три сообщения на карту и место публикации. Проверка идёт в обычном цикле бота; это наблюдённые цены, а не запись каждого тика биржи.

Пример:

```text
📈 Кэф на Команду A вырос, карта 2: 1.50 → 1.80 (+20%)
🏆 EPL Masters 2026
ℹ️ Polymarket · 18:35 МСК. Исходный прогноз: 58%, ★
```

Сообщение приходит ответом на тот прогноз, который был опубликован в конкретной группе или канале, с сохранением темы группы. Оно не меняет фаворита, процент, картинку и сохранённую оценку модели.

Условия: автопубликация и источник включены, турнир отслеживается, карта не завершена, прогноз опубликован минимум три минуты назад, обе текущие цены свежие и относятся к одной карте, одному рынку и одинаковым правилам. Исторические точки не запускают уведомления. Крайние цены ниже 2% или выше 98% пропускаются, поскольку незакрытый рынок может уже отражать завершённую карту. При смене рынка новая начальная цена записывается без сообщения о ложном скачке.

Доставка имеет отдельную запись в журнале `odds_alert:N`. Если Telegram не подтвердил результат отправки, бот не повторяет сообщение автоматически. Для ручного подтверждения после сверки используется `/confirm ID odds_alert:N MESSAGE_ID CHAT_ID`.

Параметры `.env`, если нужны значения вне кнопок админки:

```dotenv
ODDS_ALERTS_ENABLED=true
ODDS_ALERT_RELATIVE_INCREASE=0.20
ODDS_ALERT_MIN_INCREASE=0.20
ODDS_ALERT_COOLDOWN_SECONDS=600
ODDS_ALERT_MAX_PER_MAP=3
```

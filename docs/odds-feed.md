# Подключение дополнительных площадок

Основной источник — Polymarket, запасной — сохранённая предматчевая линия Fonbet через OddsPapi. Прямые API 1win, BetBoom, Winline и российского PARI не подтверждены. Площадка появляется в карточке только после получения проверенных котировок; кнопка включения не создаёт подключение.

## Контракт JSON-источника

Задайте `ODDS_FEED_URL` и, если нужен, `ODDS_FEED_API_KEY` в `.env`. Бот делает GET с `match_id` в query и передаёт ключ в `Authorization: Bearer …`. Источник должен уже иметь подтверждённое соответствие своей игры Dota match ID.

Пример формата (числа условные):

```json
{
  "quotes": [{
    "source": "BetBoom",
    "match_id": "1234567890",
    "market": "map_winner",
    "outcome": "radiant",
    "odds": 1.85,
    "observed_at": "2026-10-10T15:00:00Z",
    "source_updated_at": "2026-10-10T15:00:00Z",
    "map_number": 2,
    "line": null,
    "rules": "verified-map-winner-rules-v1",
    "active": true,
    "url": "https://example.com/event/123",
    "gross": false,
    "liquidity": null,
    "market_id": "source-market-123"
  }]
}
```

`source_updated_at` в этом контракте — время подтверждённого наблюдения у источника. Это не просто время последнего движения цены. Кэш нельзя обновлять новым временем без нового наблюдения линии.

Допустимые `source`: `1win`, `BetBoom`, `Winline`, `PARI`. Исходы победителя: `radiant`, `dire`. Для `duration_total`: `over`, `under`, а `line` задаётся в минутах. ТБ 38.5 сравнивается только с ТБ 38.5 по тем же правилам. Неверные и устаревшие записи отклоняются.

`rules` — идентификатор проверенной совместимости условий расчёта. Разные условия должны иметь разные значения. `gross=true` обозначает предварительную цену до неизвестных расходов. Такие записи не выбираются лучшими в одной группе с ценами, где расходы учтены.

## OddsPapi

OddsPapi (`oddspapi.io`) и The Odds API (`the-odds-api.com`) — разные поставщики. `ODDSPAPI_API_KEY` принимает только ключ OddsPapi. Ключ The Odds API хранится отдельно как `THE_ODDS_API_KEY` и используется диагностикой `betbot doctor` для проверки покрытия. Проверка `/v4/sports?all=true` 14 октября 2026 вернула 180 записей без Dota 2 или других киберспортивных дисциплин. Адаптер котировок Dota 2 для этого сервиса не включён; ключ не отправляется в OddsPapi. Само наличие рабочего ключа не подтверждает наличие нужного рынка.

Для Fonbet достаточно `ODDSPAPI_API_KEY`. `betbot doctor` проверяет ключ через бесплатный `/account`, показывает доступ к Dota 2 / Fonbet, live-права и остаток квоты, не расходуя платный запрос на каталог букмекеров. Проверенный 14 октября 2026 бесплатный тариф: 250 запросов в месяц, Fonbet доступен до начала серии, запрос live-матча возвращает `403 RESTRICTED_ACCESS`. В каталоге этого ключа не обнаружены 1win, BetBoom, Winline и российский PARI; MegaPari и FairPari — другие площадки.

Worker получает каталог рынков Dota 2 раз в неделю, каталог матчей выбранных турниров раз в сутки и пакет предматчевых линий только `bookmakers=fonbet` через `/odds-by-tournaments`. Первичная загрузка сохраняет доступные цены, затем бот пытается повторить снимок в течение последних пяти минут перед известным началом серии. Матчи с одинаковым временем обновляются одним пакетом. Добавленные в пакет новые раунды попадают в расписание следующих запросов.

`ODDSPAPI_DAILY_REQUEST_LIMIT=8` ограничивает расход за день МСК. Запрос резервируется в SQLite до отправки, включая ошибки и перезапуски; автоматических повторов платного HTTP-запроса нет. Отдельно проверяется месячный остаток аккаунта. При нехватке квоты дополнительный снимок не выполняется, сохраняется предыдущий. Поэтому последние пять минут — целевое окно, а не обещание последней цены перед стартом каждого матча. `ODDSPAPI_PREFETCH_SECONDS=86400` задаёт период фонового обновления каталога; события перед стартом проверяются независимо от этого периода. При выключении Fonbet в админке сбор прекращается.

Сохраняются только активные предложения Fonbet, событие Dota 2 со статусом pre-game и будущим временем начала, парные исходы и явно пронумерованные рынки карт 1–5. ID и ориентация исходов берутся из каталога (`outcomeName=1/2`), а не из порядка массива. Победитель всей серии не подставляется в отсутствующий рынок карты. Для назначения цены прогнозу должны однозначно совпасть команды, турнир, время и подтверждённый номер карты. Кэш переживает перезапуск, но его время никогда не обновляется без нового запроса. `changedAt` сохраняется отдельно: это последнее изменение цены, а не время получения линии.

Выбор площадки фиксируется в исходном прогнозе: пригодная цена покупки Polymarket имеет приоритет, затем используется `prematch_reference` Fonbet. Позднейшие цены не изменяют выбранный источник или исходный кэф. В посте и карточке — только площадка и коэффициенты; время и происхождение остаются в журнале. Движение коэффициентов всегда сравнивается внутри Polymarket. Подробности расчёта такого запасного кэфа — в [описании виртуального банка](paper-bank.md).

## Polymarket

Поиск событий использует каталог Dota 2. Для V2 используются `positionIds`, для CTF — `clobTokenIds`. Рыночный ориентир и цена покупки (`1 / ask`) сохраняются отдельно: публичная карточка показывает ориентир, виртуальный банк использует исходную цену покупки. Подробности, включая условное использование рынка серии для решающей карты, — в [описании банка](paper-bank.md).

Привязка безопасна в двух режимах:

- `/market MATCH_ID EVENT_ID` после проверки события администратором;
- `/polyfilter LEAGUE_ID ЧАСТЬ НАЗВАНИЯ ТУРНИРА` вместе с единственным совпадением обеих команд и времени события. Неоднозначные совпадения пропускаются.

Для номера карты используется поле live-источника, необязательный `STEAM_API_KEY` или `/map MATCH_ID НОМЕР`. Номер не угадывается из активных ставок на следующую карту. Без подтверждённого номера бот ждёт следующего обновления до создания прогноза и ставки банка.

Разные названия команд задаются через `/alias TEAM_ID ИМЯ НА POLYMARKET`. Если предварительный прогноз уже создан, `/refresh MATCH_ID` сохраняет новую предварительную версию, оставляя старую в истории. Опубликованные прогнозы неизменны.

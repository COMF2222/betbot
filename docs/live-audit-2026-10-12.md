## Следующая проверка

Публикуемая модель: `logistic-v2-89bc7fac69d6`. Кандидат: `glicko-team-research-v1-aea4609b642d`. Параллельная модель включается через `SHADOW_MODEL_PATH=data/model-shadow.json`.

Перед получением результата бот сохраняет прогноз кандидата для **того же драфта** в `shadow_forecast:<match_id>`. Он не отправляется в Telegram и не меняет основной прогноз. Истории рейтингов активной модели и кандидата независимы. Повторная обработка не перезаписывает сохранённый прогноз кандидата.

Заранее фиксируем первые 100 пригодных пар будущих прогнозов. Отчёт показывает все карты, Brier, отдельную точность сигналов с их количеством, различия фаворитов и разбивку по турнирам. Не включаем прогнозы, записанные после фактического конца карты или подтверждения результата, либо с историей из будущего. Карты одной серии зависимы; 100 карт не означают автоматическое доказательство превосходства. Автоматического переключения модели по результатам нет.

На сервере:

```bash
cd /root/betbot-server
docker compose --project-name betbot --env-file deploy.env -f compose.yaml -f compose.mihomo.yaml exec -T betbot python scripts/shadow_report.py --output data/shadow-report.json
```

Команда только читает SQLite и сохраняет JSON-отчёт. Она не создаёт `Store`, не меняет состояния отправки и не публикует сообщения.

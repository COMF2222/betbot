# Карточки BETBOT

Карточка прогноза: 1280 × 840. Итоги дня и недели: 1280 × 720. Обе используют общий Canvas, типографику и палитру в `src/betbot/graphics.py`.

| Назначение | Токен | Цвет |
| --- | --- | --- |
| Основной текст | WHITE | #F7FAFF |
| Вторичный текст | MUTED | #B6C5D9 |
| Свет | CYAN | #71F0E1 |
| Тьма | AMBER | #FFCA8A |
| Верный исход | GREEN | #77EDB5 |
| Промах | RED | #FF8DA0 |
| Звёзды | GOLD | #FFD388 |
| Панель | PANEL | #152238 |
| Котировки и нижняя строка | SURFACE | #1C2C45 |
| Вложенная подложка | SUBTLE | #0E192A |

Основной шрифт — Manrope (500/800). Для японских и китайских символов в никах — Noto Sans JP (500/700). Файлы и лицензии OFL включены в пакет, поэтому Windows и Linux используют одинаковые шрифты. Источники: [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope), [Noto Sans JP](https://github.com/google/fonts/tree/main/ofl/notosansjp).

Поля изображения — 56 px, межблочный промежуток — 24 px. Команды имеют фиксированную текстовую колонку, длинные названия занимают до двух строк. Портреты сохраняют пропорции; ники центрируются по видимым пикселям относительно портрета. Логотип центрируется по заполненной части глифа. Кэфы стоят в отдельных колонках и не обрезаются вместе с названием команды.

В прогнозе первыми читаются команда и основная вероятность, затем сравнение по драфту и цены. В отчёте — счёт и точность, затем результаты карт. Номер карты выводится отдельно от длинного названия пары команд. Условия задержки и отдельного учёта берутся из сохранённых данных.

Контраст обычного текста, вторичного текста и акцентных чисел на панелях проверяется по WCAG AA. Геометрические проверки покрывают длинные названия, вероятности вплоть до округлённых 100%, крупные счётчики, центрирование логотипа и ников. Перед выпуском изображения проверяются также в уменьшенном виде шириной 390 px.

Для предпросмотра без отправки в Telegram и без записи в базу:

```powershell
uv run python scripts/preview_cards.py
uv run python scripts/preview_cards.py --input artifacts/public-ui-preview.json --date 2026-10-11
```

Вход прогноза — сохранённый JSON `Prediction`. Для отчёта можно указать `--report JSON`; иначе читается локальная база в режиме только чтения. Результат — PNG в `artifacts/cards-v3`, включая маленькие копии и проверку длинных названий. Прогнозы с изменёнными названиями для проверки макета отмечаются как демонстрация.

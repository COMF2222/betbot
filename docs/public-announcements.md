# Расписание и анонсы

В «Публикации» находятся два независимых переключателя:

- **Утренний анонс** — картинка с матчами дня и короткое сообщение в 10:00 МСК.
- **Анонсы турниров** — отдельные карточки выбранных турниров с датами, участниками, организатором и призовым фондом, если они подтверждены.

Расписание включает только турниры, включённые в отслеживание. Основной источник — страницы Liquipedia, найденные по настоящему Steam league ID и повторно проверенные по infobox. Это позволяет включать серии без рынка Polymarket. Время переводится в МСК по указанному часовому поясу; неизвестное время не придумывается. Статус LIVE подтверждается источником рынка или свежим списком live-карт. Завершённые серии исключаются из утреннего списка.

Polymarket дополняет расписание отметкой о наличии рынка. Карточка показывает до семи ближайших или текущих серий и число оставшихся. Недоступность Polymarket не мешает публикации подтверждённого расписания Liquipedia.

Анонс приходит один раз для конкретного этапа. Регионы квалификации могут иметь общий Steam ticket: для одного такого турнира в одно место приходит не больше одного анонса за сутки. После паузы или отключения автопубликации ничего не отправляется. Журнал публикаций предотвращает дубли после перезапуска и неоднозначного ответа Telegram.

Официальные логотипы берутся из infobox команды на Liquipedia и сохраняются в `data/team-logos`; без подтверждённого изображения используется знак с инициалами. Необъявленные участники не подменяются командами из другого турнира. Призовой фонд квалификации не наследуется от основной стадии.

Дизайн использует общий Canvas BETBOT, Manrope, тёмный фон, бирюзовый и янтарный акценты. Проверены длинные названия, китайские имена, неизвестные участники, пределы текста внутри изображения и просмотр в уменьшенном размере. Источники указаны внизу карточки.
